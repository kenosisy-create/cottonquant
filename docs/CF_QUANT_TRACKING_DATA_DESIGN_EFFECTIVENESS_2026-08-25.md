# CF量化追踪：数据内容、设计逻辑与效果评估

> 整理日期：2026-08-25  
> 期货/期权主数据截至：2026-08-21  
> 定位：CF日频研究级生产数据决策工作台，不是自动交易系统。

## 一、先说结论

Cottonquant目前已经完成了一个可复算、可追溯的CF量化追踪底座。它最有效的部分是：

1. 把郑商所期货、期权日线转换成统一的raw/core/research数据链路。
2. 区分研究主力、全合约持仓、移仓、交割和套保结构，避免把CF611这类结构性活跃合约误当成唯一方向代表。
3. 同时观察动量、carry、期限曲线、持仓压力、趋势阶段和期权结构，能够识别市场内部的同向、分歧和衰竭。
4. 使用T+1、真实合约、成本和样本外检验，能够阻止未来函数，并及时否决没有稳定增量的复杂策略或期权因子。

但必须明确：

- **数据生产能力已经有效。**
- **市场结构解释能力已经有效。**
- **稳定、跨年度、成本后方向alpha尚未证明。**
- **期权目前具有结构解释价值，但没有证明稳定的1D/3D/5D预测增量。**
- **基本面数据目前仍是观察侧车，不能进入主信号。**

因此，系统当前的正确用途是辅助研究员判断“发生了什么、结构是否一致、什么条件会确认或破坏当前判断”，而不是承诺自动抓住每一次反弹或趋势。

## 二、量化数据的主要内容

### 2.1 官方期货行情底座

核心表：`data/core/CF/core_quote_daily.parquet`

| 项目 | 当前覆盖 |
| --- | --- |
| 日期 | 2021-01-04至2026-08-21 |
| 交易日 | 1,366个 |
| 记录 | 8,196行 |
| 主要字段 | 开、高、低、收、结算、前结算、成交量、持仓量、成交额、合约代码 |
| 来源追踪 | source snapshot、SHA256、raw manifest |

这张表保留每个可交易合约的日度事实，是所有合约链、因子、趋势和回测的基础。研究层不得直接解析交易所原始文件。

### 2.2 官方期权行情底座

核心表：`data/core/CF/core_option_quote_daily.parquet`

| 项目 | 当前覆盖 |
| --- | --- |
| 日期 | 2021-01-04至2026-08-21 |
| 交易日 | 1,366个，与期货日期集合一致 |
| 记录 | 304,070行 |
| 主要字段 | 期权代码、标的合约、C/P、行权价、结算价、成交量、持仓量、虚实值、流动性和质量标签 |

期权底层数据支持按标的月份、行权价、到期桶和流动性筛选，但公开持仓只能看到总量，不能识别买方、卖方、产业身份或做市商Gamma。

### 2.3 会员持仓数据

核心表：`data/core/CF/core_member_position_daily.parquet`

| 项目 | 当前覆盖 |
| --- | --- |
| 日期 | 2021-01-04至2026-07-20 |
| 记录 | 419,593行 |
| 主要字段 | 合约、名次、会员、持仓方向、持仓值、持仓变化 |

会员数据用于Top20集中度、同侧迁移和结构归因。它是席位级、排名范围内的可见代理，不等于客户真实净敞口。目前最新日期落后于期货主数据，不能冒充8月最新会员事实。

### 2.4 基本面与产业链侧车

基本面不进入`signal_matrix`或`composite_score`，只提供历史背景和人工复核上下文。

| 数据类别 | 内容 | 历史起点 | 最新观察 | 当前状态 |
| --- | --- | --- | --- | --- |
| 现货/基差 | 3128B、地区现货、活跃合约价格和基差 | 2000/2004 | 2026-07-03 | 过期，只能历史解释 |
| 库存 | 商业库存、工业库存、新疆/内地结构 | 2009-11 | 2026-06-15 | 月频滞后 |
| 仓单 | 郑商所一号棉仓单汇总 | 2004-10 | 2026-07-03 | 过期，缺仓库/质量明细 |
| 进口 | 数量、金额、累计和同比 | 1998-01 | 2026-05-31 | 月频过期 |
| 纺织链 | 纱厂/织厂负荷、棉花/棉纱/坯布库存 | 2018-11 | 2026-07-03 | 周频过期 |
| iFinD EDB | 3128B、棉纱价格、抛储事件、外汇掉期曲线 | 2025-07 | 2026-08-05/06 | 侧车，不能替代即期汇率 |

截至2026-08-21的基本面状态表包含82项：`EVENT_DRIVEN=4`、`LAGGING=5`、`STALE=68`、`MISSING=5`。缺失项包括ICE棉价、USD/CNY即期、棉纱利润、纺织订单和仓单质量/仓库明细。

### 2.5 合约链、连续对象和真实交易映射

系统同时维护三种对象：

1. **全合约链**：观察所有挂牌月份的价格、成交和持仓分布。
2. **调整连续对象**：消除换月机械跳空，用于收益、动量和波动信号。
3. **真实合约映射**：用于T+1成交、成本、持仓和损益复算。

调整连续价只是统计信号对象，不是棉花现货公允价，也不能与18,600目标价格补贴直接平行比较。

## 三、主要量化因子和分析角度

### 3.1 价格与动量

- 主力结算价1D/3D/5D/10D/20D/40D变化。
- 20日动量、均线位置、波动率、MFE和MAE。
- 收盘价与结算价双口径：收盘反映日终交易状态，结算用于官方日频、保证金和稳定复算。

设计目的：识别价格变化的方向、速度和持续性，同时避免只看一天涨跌。

### 3.2 Carry与期限曲线

- 主力与近月/远月价差。
- 年化carry proxy。
- 曲线斜率、跨月价差和结构突变。

设计目的：CF是季产年销商品。趋势不仅来自价格动量，也可能来自库存、交割、套保和新旧棉年度之间的时间定价。

### 3.3 成交、持仓和移仓

- 主力持仓压力、成交/持仓变化。
- 全链总持仓变化、远月承接和移仓比例。
- 主力、次主力和03/07/11结构性合约分别观察。
- Top20会员同侧迁移、跨期配对和集中度代理。

设计目的：不能把“主力减仓”直接解释成资金离场。必须确认其他合约是否承接，也不能因CF611持仓很大就把它当成棉花方向主力。

实际案例中，CF611异常持仓研究发现：2026-05-15至2026-07-20，可见的CF609至CF611同侧gross移仓代理约占CF611正向净增仓的54.28%；仓单变化不能单独解释异常增仓。这说明全链和会员结构比单合约持仓更有解释力。

### 3.4 趋势阶段与生命周期

趋势状态分为：

- `S0`：未确认或信号分歧。
- `S1`：起点观察。
- `S2`：趋势中。
- `S3`：衰竭观察。
- `S4`：终点确认。

系统不只用固定N日收益评价趋势，还补充状态转移、事件episode、TBM首触、MFE、MAE和首次解决检查点。

设计目的：固定持有期容易错配趋势生命周期。事件标签用于回答“信号何时确认、何时失败、通常几天解决”，固定1D/3D/5D/10D/20D/40D仍保留为统一基准尺。

### 3.5 期权定价与关键点位

基础期权变量包括：

- ATM IV proxy和IV rank。
- PCR成交量、PCR持仓量。
- skew proxy和流动性评分。
- Call/Put静态墙、局部动态墙。
- 墙位迁移、1/3/5日OI变化、建仓/撤仓不对称。
- 到期桶、IV-RV、期货与期权方向背离及解决周期。

设计目的：期权结构可以揭示波动风险定价和结构性矛盾，但不能先验地把Call墙解释为阻力、Put墙解释为支撑。研究按2021早期低活跃、2022-2023扩张、2024-2026成熟活跃三个阶段分别检验，避免把早期期权市场结论直接外推到当前。

### 3.6 基本面和政策上下文

- 现货、基差、仓单、库存、进口。
- 纺纱和织布负荷、纱布库存、纱价。
- 棉花年度、目标价格补贴、抛储等事件上下文。

设计目的：棉花具有明显的年度、政策和产业属性，单纯价格因子不能解释所有行情。但基本面数据必须保留统计期、发布日期、修订和口径切换，禁止把月频/周频数据向前填充成伪日频。

## 四、为什么采用现在的架构

| 设计 | 原因 |
| --- | --- |
| raw/core/research分层 | 保留原始证据，标准化事实与研究推导分离，结果可追溯 |
| 郑商所官方文件优先 | 避免第三方连续合约和字段口径不透明 |
| 01/05/09研究主周期+全链观察 | 适应CF真实主力轮换，同时保留03/07/11交割和套保结构 |
| 收盘与结算双价格 | 收盘用于破位和日终状态，结算用于官方复算与策略记账 |
| 连续价只做信号、真实合约做损益 | 防止换月调整值被误当成真实可交易价格 |
| T日信号最早T+1执行 | 消除T日结算后信号赚取T至T+1收益的未来函数 |
| 固定周期+事件生命周期并行 | 兼顾横向可比性和趋势路径依赖 |
| 期权作为解释侧车 | 公开OI缺少买卖方归属，不能直接进入方向评分 |
| 基本面按发布日期对齐 | 避免数据回填、修订和频率错配造成前视偏差 |
| 日更轻量、周更验证 | 日更回答当前事实，历史证据和审计不拖慢日常更新 |

## 五、实际追踪效果

### 5.1 工程与数据效果：强

- 期货和期权日期覆盖一致，当前各1,366个交易日。
- 交易所日文件可以自动下载、校验、留存并写入core。
- raw snapshot、checksum和manifest可以追溯每次研究输入。
- 信号矩阵已覆盖1D/3D/5D/10D/20D/40D，并明确最新快照不含未来收益标签。
- 全链持仓模块能区分单日增减仓、主力迁移和远月承接。

这一层已经具备稳定研究生产价值。

### 5.2 市场结构解释：中强

系统能够同时给出：

- 当前研究主力和其他活跃合约的角色。
- 价格上涨/下跌伴随全链增仓还是减仓。
- carry、曲线、动量和持仓是否同向。
- 期货与期权是确认、背离还是波动未定价。
- 异常持仓更可能由移仓、跨期、套保还是新资金共同构成。

它明显优于只看主力K线、主力单日持仓或静态Put/Call墙。

### 5.3 趋势起终点识别：中弱、仍不稳定

S0-S4和生命周期框架可以规范描述趋势路径，但尚未证明稳定的跨年度趋势起点预测能力。2024等失败窗口说明阶段规则仍有regime敏感性。

系统目前更适合输出“起点观察、确认条件、衰竭风险和失效条件”，不适合把S1直接当作高胜率入场信号。

### 5.4 四因子与策略效果：弱，已有明确约束

截至2026-07-17的历史策略验证：

| 策略 | 全历史净收益 | Sharpe | 最大回撤 | 结论 |
| --- | ---: | ---: | ---: | --- |
| `CF_tsmom_v0` | 13.94% | 0.266 | -15.97% | 可作为研究基准，但年度稳定性不足 |
| `CF_phase_gated_v0` | -1.81% | -0.044 | -11.33% | `FROZEN` |

复杂阶段门控只在2/5个完整年度跑赢基准，全历史保守成本后`Delta Sharpe=-0.310`。这说明增加阶段、carry和期权条件没有自然转化为更强策略。

### 5.5 期权追踪效果：解释有效，预测无效

R93R统一证据门控覆盖2021-01-04至2026-08-21：

- 统一证据873条。
- 成本敏感记录198条。
- 期货参考基准`KEEP=3`。
- 期权预测候选`KEEP=0`、`WATCH=1`、`REJECT=869`。
- 唯一WATCH为`EXPIRY_DTE_6_15 / 5D`，样本48、FDR q=1.0、完整年度OOS支持0/1，不具晋级资格。
- 最终裁决：`REJECT_STOP_OPTION_FACTOR_EXPANSION`。

事件路径研究进一步显示，方向性事件总体延续率46.27%、反转率46.12%、未解决率7.61%，接近随机分布。期权事件通常在1至约1.4个固定检查点首次出现方向性结果，但“解决快”不等于“方向可预测”。

有效结论是：期权可以描述矛盾、波动风险、到期和点位迁移；无效结论是：动态墙、Call/Put OI变化或期货-期权背离可以稳定预测未来5日方向。

### 5.6 基本面追踪效果：历史解释有用，最新决策不足

基本面历史跨度较长，能够用于解释库存周期、进口、仓单和纺织链背景。但当前大量指标滞后或过期，且基本面增量研究没有形成严格、稳定的正向候选。

因此基本面目前只能回答“当前行情可能处于什么产业背景”，不能独立生成方向，也不能补足期货最新日信号。

## 六、2026-08-21最新样本如何体现系统价值

最新信号矩阵显示：

- 研究主力：`CF701`，结算价17,070。
- 趋势阶段：`S3 / 衰竭观察`，趋势质量31，置信度低。
- 动量和持仓方向偏多，carry和曲线方向偏空。
- 1D/3D/5D仍偏多，10D/20D中性，40D偏空。
- ATM IV rank约6.73%，PCR OI约0.878，期权方向偏多，但不具备历史晋级资格。
- 5日CF701持仓增加111,495手，其他月份正向承接24,639手，全链增加52,813手；这不是简单的“主力减仓移仓”情形。

这个结果的价值不是给出一句“做多”或“做空”，而是识别出：短期价格和持仓仍有多头延续，期限结构并未确认，趋势已进入衰竭观察，期权证据不能升级方向。这是一个需要等待确认或失效条件的结构冲突状态。

## 七、已经证明和没有证明的内容

### 已经证明

1. CF官方日频数据链路可稳定生产和复算。
2. 全合约链、01/05/09主周期和真实换月映射是必要的。
3. 连续价格与真实成交合约必须分离。
4. T+1和后验标签分离能有效阻止未来函数。
5. 复杂phase-gated策略没有通过历史晋级。
6. 当前期权因子没有稳定预测增量，应停止继续搜索阈值。
7. 会员持仓和期权墙更适合结构归因，不适合直接作为方向开关。

### 尚未证明

1. 四因子同向能够稳定预测10D/20D收益。
2. S1能够稳定转化为S2并形成可交易趋势。
3. 期权`confirm_long`等标签代表真实机构方向确认。
4. Put墙是支撑、Call墙是阻力或可以推断dealer gamma。
5. 基本面代理能够在发布时间对齐后稳定提高方向命中率。
6. 当前系统能够稳定提前抓住政策或宏观催化驱动的快速反弹。

## 八、当前最合理的使用方式

每日重点看：

1. 数据是否更新完整，研究主力是否发生变化。
2. 收盘和结算是否同时破位，短中长周期方向是否一致。
3. 主力持仓变化是否由全链增仓、减仓或移仓承接解释。
4. carry和曲线是否确认价格趋势。
5. 期权是否出现异常波动定价、墙位迁移或期货-期权分歧。
6. 当前阶段的确认条件、衰竭条件和失效条件。

每周重点做：

1. 更新历史后验标签、事件生命周期和成本敏感性。
2. 检查候选是否跨年度、样本外和FDR稳定。
3. 刷新基本面新鲜度和发布时间状态。
4. 对新研究分支执行`KEEP/WATCH/REJECT`，避免系统继续膨胀。

## 九、总体评价

| 能力 | 当前评价 |
| --- | --- |
| 官方数据接入与留痕 | 强 |
| 合约、移仓和全链结构 | 强 |
| 日度市场状态描述 | 中强 |
| 趋势阶段解释 | 中 |
| 趋势起点预测 | 弱/不稳定 |
| 四因子方向alpha | 弱/未证明 |
| 期权结构解释 | 中 |
| 期权短周期预测 | 弱/已停止扩张 |
| 基本面历史解释 | 中弱 |
| 基本面最新决策支持 | 弱 |
| 自动交易适用性 | 不适用 |

最终判断：**项目并没有作废，它已经成功成为CF市场结构和研究证据工作台；但它尚未成为稳定盈利的量化策略。下一阶段的价值不在继续堆数据或增加因子，而在保持数据新鲜、使用少数清晰假设、严格验证并及时停止无效研究。**

## 研究边界

- Forward return只作为历史后验验证标签，不参与最新日信号生成。
- 调整连续价不是可交易价格，回测和损益必须使用真实合约。
