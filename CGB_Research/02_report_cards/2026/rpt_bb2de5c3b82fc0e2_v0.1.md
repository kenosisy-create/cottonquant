# 4. 传导链与竞争性解释 `[I]`

## 4.1 报告主链

**油价—通胀—利率链**：地缘供给冲击 → 近端油价和现货风险溢价上升 → 若远端油价仍稳定，则中长期通胀预期较早企稳 → 美债波动率和全球金融条件的冲击缓和 → 美元、风险偏好和跨境资金压力变化。进入中国国债体系时，还需经过人民币、国内通胀、央行操作与资金面确认。

**政策框架—期限溢价链**：美联储反应函数不清 → 市场难以锚定利率路径 → 不确定性补偿上升、短长端对数据与沟通更敏感 → 美债曲线和美元波动 → 全球折现率、人民币及风险偏好变化。该链只定义外部压力的方向，不定义中国利率的最终方向。

**K型增长—政策等待链**：AI投资支撑总量增长，但消费、收入、住房与传统部门偏弱 → 总量韧性和结构脆弱并存 → 加息的部门成本上升 → 报告基准情景倾向按兵不动 → 美债更可能区间交易而非持续熊市。

**美元—人民币—国内债券接口**：美国—G7利差和政策预期推动美元，全球风险偏好与持仓拥挤形成反向约束 → 美元/CNH及结售汇压力变化 → 国内货币政策操作空间、外资流动与风险偏好可能变化 → 只有当这些变化与国内资金、信用和供给同向时，才可能形成可交易的中国国债外部信号。

## 4.2 竞争性解释

1. **远端油价稳定不只意味着供给冲击可被消化**：也可能代表全球需求走弱。前者偏向“通胀冲击缓和”，后者还会改变增长预期；必须把远近月价差、需求指标和通胀互换联合辨别。
2. **美债期限溢价上升不只来自美联储沟通**：财政赤字、再融资供给、海外配置需求和国债市场流动性都能解释同一现象。报告在第34页提及财政部再融资会议，但没有量化各因素贡献。
3. **美元强弱不能只由利差解释**：全球去杠杆时美元可能因流动性需求上涨，风险偏好回升时即便利差仍高也可能走弱。第31页本身即承认驱动相互对冲。
4. **海外利率与中国利率可能阶段性脱钩**：国内资金、信用、财政供给、资产配置和资本流动约束能够覆盖海外冲击。美债变化至多是条件变量，不是CGB因变量的充分解释。
5. **消费韧性可能依赖资产价格**：报告把财富效应视为支撑，但若权益去杠杆持续，财富效应和金融条件可能同步反向，导致消费对风险资产具有非线性反馈。

# 7. 估值、市场定价与情景

- 报告是否提供估值锚：提供美元指数98.4-102区间、10年期美债收益率3.95%-4.65%区间和10Y-2Y约20bp观察位；这些均为2026H2策略锚，不是长期公允价值。
- 是否使用历史分位或历史样本：使用金融条件、持仓z-score、经济惊喜、期限溢价和宏观模型，但没有披露全部样本、权重、显著性与复算步骤。
- 是否讨论市场已经定价多少：报告指出市场对2027H1可能定价过于鹰派、长期通胀预期与政策路径出现分化，并认为美元多头拥挤；这些属于相对定价判断，仍需外部市场数据复算。
- 基准情景：美国增长有韧性但结构分化，通胀趋势回落而中枢偏高，美联储按兵不动；美债和美元以区间为主。对中国国债只意味着外部压力不形成单边持续强化，国内条件仍决定最终方向。
- 鹰派/外部收紧情景：核心通胀向上、联储建立更强硬反应函数、财政再融资供给增加、美元与美债收益率同升。若同时伴随CNH走弱和国内资金趋紧，才构成中国中长端收益率上行的强化情景。
- 去通胀/风险缓和情景：远端油价稳定、正式通胀回落、联储继续等待、美元和美债收益率下降。若国内信用和供给也不构成反向压力，才可能转化为中国中长端债券的外部顺风。
- 风险资产去杠杆情景：美元可能因流动性需求走强，美债可能受避险与期限溢价两股力量影响；此时不能用简单“股跌债涨”映射中国国债，应同时观察MOVE、DXY、CNH和国内资金。

# 8. 适用环境、非线性与失效区间

- 适用市场环境：地缘供给冲击但远端价格可交易；美国增长总量韧性与结构走弱并存；政策反应函数不清；全球资产在通胀、流动性和风险偏好之间切换主导变量。
- 机制可能增强的区间：油价近端上行而远端稳定；通胀互换与美债波动率同向回落；DXY、美债收益率、CNH和国内利率出现一致的事件响应。
- 机制可能钝化或反转的区间：财政供给主导美债；全球流动性挤兑推动美元与美债相关性改变；中国国内流动性和信用政策对冲外部冲击；人民币由贸易流而非利差主导。
- 仅适用于当期的叙事：2026年中东冲突、沃什政策框架“真空期”、美元98.4-102区间、美债3.95%-4.65%区间、10Y-2Y约20bp、AI板块去杠杆。不得直接外推到其他年份。
