# 1. 研究问题与报告答案

- 报告试图回答的问题：债基久期处于高位是否会系统性推升利率、基金降久期时抛压如何分布于10年和30年国债、以及什么指标可能较早识别久期拐点。

# 4. 传导链与竞争性解释 `[I]`

## 4.1 报告主链

绩优基金久期斜率转负或与整体久期差收窄 → 基金久期策略由分歧走向减仓共识 → 降久期初期优先出售流动性较好的10年现券 → 若收益率上行趋势进一步确认，30年现券因利率敏感度更高而承受更大边际卖压 → 10年/30年收益率与30-10利差呈现阶段性变化。

这条链是对报告论证的结构化重述，不是经本卡片验证的因果关系。报告本身也强调基金行为“不决定利率整体方向”。

## 4.2 竞争性解释

1. 宏观基本面、货币政策或风险偏好变化可能同时推动收益率与基金久期调整，使基金久期成为同步或滞后变量，而非触发变量。
2. “绩优前20%”可能因当期长久期资产表现较好而机械筛入高久期基金，形成按业绩选样后的内生相关；如果没有固定排名窗口和无前视偏差的再平衡规则，两周领先可能被高估。
3. 基金久期、基金买卖为周度或未声明频率，而国债收益率通常可高频观察；报告没有披露重采样、周末对齐或缺失值规则。不同对齐方法可能改变所谓领先/滞后关系。
4. 银行、保险、理财、自营和外资等其他机构可能主导曲线变化。即使基金卖压方向成立，也只能解释边际冲击，不能据此确定收益率总方向。
