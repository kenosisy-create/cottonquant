# 4. 传导链与竞争性解释 `[I]`

## 4.1 报告主链

**政策路径链：** 三张偏紧异议票 → 市场上调加息尾部风险 → 记者会未给可操作门槛 → 9月加息概率从盘中约70%回落至约60% → 2-5年美债更敏感于后续通胀和就业数据。

**期限溢价链：** 主席弱化路径承诺并认可市场自行收紧 → 长期政策与通胀锚的不确定性没有消失 → 财政供给、实际利率和期限溢价风险补偿上升 → 10年与30年美债收益率未随短端加息预期降温而下行 → 曲线熊陡。

以上两条链是对报告论证的结构化重组，不是本卡完成的因果识别。

**进入中国国债前的条件桥接：** 美国通胀/政策预期 → 美债曲线与美元 → 人民币汇率、跨境风险偏好和国内政策约束 → 中国资金面与本土增长/通胀预期 → 中国国债收益率曲线 → TS/TF/T/TL。任何一环若被国内宽松、弱基本面、配置需求或汇率稳定所抵消，海外冲击都可能不传导或只短暂传导。

## 4.2 竞争性解释

- 长端收益率上行可以由财政赤字、长债供给、实际利率、通胀预期、期限溢价、事件仓位或流动性共同解释；单次FOMC盘中表现无法区分各项贡献。
- 记者问答后短端加息概率下降，也可能包含事件前定价过满、获利了结或流动性因素，不一定完全由沃什表述造成。
- 三张异议票可能表达通胀信誉压力，也可能只是个别票委的偏好；只有后续票型扩散、经济数据与沟通一致时，才支持“委员会反应函数整体转鹰”。
- 对中国国债而言，美债上行既可能通过美元与风险偏好形成阶段性利空，也可能通过全球增长/风险事件提升避险需求；国内政策和资金面通常决定传导强弱，报告本身没有提供辨识证据。

# 7. 估值、市场定价与情景

- 报告是否提供估值锚：提供10年期美债收益率4.5%-5.0%的核心博弈区间，但没有披露估值模型、参数、历史样本或置信区间，因此只能作为报告情景锚。
- 是否使用历史分位或历史样本：使用1936年以来FOMC异议票历史和2011年、2016年案例，但未给政策结果的统计概率；期限溢价和收益率区间没有披露历史分位。
- 是否讨论市场已经定价多少：是。报告称会议盘中9月加息概率由约70%降至约60%，此前联邦基金期货一度计入年内接近两次加息；这些是近似、非收盘口径。
- 基准情景：9月加息仍是活跃情景，但连续加息不是清晰基准；短端围绕数据修正政策路径，10年期主要在4.5%-5.0%区间博弈。
- 上行风险情景：潜在通胀、油价和通胀预期上行，就业与需求有韧性，异议票扩散；短端重新计入加息，长端向5.0%靠拢并可能熊陡。
- 下行风险情景：核心服务通胀、能源、就业和消费降温；短端紧缩定价回撤，2-5年收益率先下行，10年向4.5%附近回落并可能牛陡。
- 中国国债情景 `[I]`：不把上述美债情景直接翻译成CGB方向。只有汇率、国内资金面和本土曲线同时确认，才进入现券与TS/TF/T/TL表达。

# 8. 适用环境、非线性与失效区间

- 适用市场环境：央行行动有限、委员会分歧扩大、前瞻指引不清晰且市场需要重新定价反应函数的事件窗口。
- 机制可能增强的区间：事件前仓位集中或定价过满；通胀与就业数据对政策分歧有放大作用；财政供给和通胀预期同时推升长端风险补偿。
- 机制可能钝化或反转的区间：主席或SEP给出清晰路径；票委分歧迅速收敛；长端上行被证实主要来自技术性供给、仓位或流动性；国内政策完全抵消海外冲击。
- 仅适用于当期的叙事：三名具体异议者、约70%至60%的盘中概率、10年/30年盘中突破点位和沃什个人沟通风格。
- 可长期复用的部分：行动、票型、沟通与市场定价分层；短端政策路径和长端期限溢价分层；事件分阶段记录；跨境传导前置过滤条件。

# 9. 隐含假设、证伪条件与反方观点

- 隐含假设：票委公开投票能代表其未来反应函数；市场盘中价格主要响应FOMC新信息；报告对记者会语义分类准确；期限溢价是长端分化的重要来源；4.5%-5.0%区间仍适用。
- 最强反方观点：所谓“短端鸽、长端鹰”只是同一事件窗口中的相关性，长端可能主要由财政供给、仓位、流动性或同步宏观消息推动，不能据此证明沟通不确定性导致期限溢价上升。
- 最小证伪集合：后续异议票不扩散或回归多数；通胀走高但委员会仍不提高政策利率；实际利率/期限溢价分解不支持报告归因；10年收益率持续脱离4.5%-5.0%；CGB在控制国内资金面后对美债事件没有稳定响应。
