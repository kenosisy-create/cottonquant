# 1. 研究问题与报告答案

- 报告试图回答的问题：2026年上半年国债期货为何由2025年的调整转为修复；结构性趋势与周期力量如何共同影响下半年利率；供给、流动性、期限品种和IRR应如何进入观察框架。

# 4. 传导链与竞争性解释 `[I]`

## 4.1 报告主链

长期链条：结构转型与信贷增速放缓 → 化债与负债主体缺位 → 可配置长久期资产相对稀缺 → 长久期配置需求上升 → 中长端收益率承受下行压力 → T、TL价格弹性大于TF、TS → 主力合约IRR维持相对低位。

短期反向链条：上半年政府债发行偏谨慎 → 下半年供给后移 → 若央行流动性对冲不足且海外加息预期持续 → 资金与期限溢价上升 → 现券收益率阶段性上行 → T、TL承受更大价格波动；待周期力量在四季度进一步消退后，结构性低利率逻辑可能重新占优。

两条链条构成报告的核心张力：长期结构趋势偏多债券价格，短期供给与外部利率环境可能造成反向波动。

## 4.2 竞争性解释

1. **避险与事件驱动解释**：2026年上半年长端走强也可能主要来自地缘冲突和避险需求，而非结构转型。报告自身承认地缘冲突是上半年上涨的重要驱动；当前证据不足以分离两者的边际贡献。
2. **配置节奏解释**：年初机构配置需求集中释放、央行结构性宽松和资金面“超宽松”均可解释价格上涨。若这些短期因素逆转，结构性低利率框架不一定能解释短期回撤幅度。
3. **持仓结构解释**：持仓增长、成交变化小和成交持仓比下降不只可能来自套保，也可能来自跨期持仓、套利、移仓节奏或低换手方向仓位；没有账户分类数据时不能确认“长期套保需求上升”的唯一性。
4. **共同趋势解释**：社融增速与十年期发行利率共同下降可能受货币政策、通胀和人口结构等第三变量影响；第10页视觉复核支持“共同趋势/同步形态”的存在，但不能确认社融或结构转型对利率的单向因果。

# 8. 适用环境、非线性与失效区间

- 适用市场环境：经济结构转型、信用扩张偏弱、机构长久期资产需求较强、货币条件总体宽松但供给扰动阶段性存在的市场。
- 机制可能增强的区间：政府债供给高峰被央行流动性充分吸收后；工业生产、价格和全球PMI转弱；T、TL持仓不拥挤且CTD/基差无异常约束时。
- 机制可能钝化或反转的区间：信用和投资持续加速；政府债供给与海外利率共同推高资金成本；长端期货出现拥挤、基差/CTD切换或流动性冲击时。
- 仅适用于当期的叙事：2026年上半年地缘冲突、2026年政府债发行后移、四季度“击球区”、AI泡沫化风险。以上不应直接沉淀为长期规律。

# 9. 隐含假设、证伪条件与反方观点
