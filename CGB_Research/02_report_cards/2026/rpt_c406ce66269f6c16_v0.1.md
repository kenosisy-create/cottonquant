# 4. 传导链与竞争性解释 `[I]`

## 4.1 报告主链

1. `[I]` 内需与融资需求偏弱 → 社融修复延后 → 宽货币、紧信用环境延续 → 短端收益率相对下行更多 → 收益率曲线陡峭化 → 期货组合以多TS、空T表达。该链综合E11-E13；报告没有证明每个箭头的独立因果效应。
2. `[I]` DR007处于政策利率之上且流动性紧张不持续 → 资金利率回落/大行融出改善 → 短债融资和持有条件改善 → TS相对走强 → 先做TS单边或多TS、空T。该链综合E03、E05、E13。
3. `[I]` 流动性收紧 → 空头套保需求增强 → 净基差上行；流动性恢复后套保压力下降 → 净基差均值回复 → 做空TS净基差，即用TS期货多头替代2年期现券。该链综合E14-E16。
4. `[I]` 经济预期修正与债市多头情绪增强 → TL因久期/价格弹性表现更强 → T-TL和近远月价差提供相对强弱验证 → 报告形成“先多TL、再多TS”的时序。该链综合E04、E06-E08、E20。
5. `[I]` 期限利差的趋势项 + 近远月净基差差异的移仓项 → 理论跨期价差；若实际价差持续偏离 → 需再检验情绪、流动性和合约因素 → 报告据此提出多TS2612、空TS2609。该链综合E17-E19。

## 4.2 竞争性解释

- `[I]` 期限利差走扩也可能由超长期国债供给、保险和银行配置需求、税收规则或久期偏好变化推动；报告没有国债发行、缴款、到期和机构净买入数据，无法把曲线变化唯一归因于社融/流动性周期。
- `[I]` TL相对强势除“多头情绪”外，还可能受超长期现券供需、可交割券结构和套保需求影响；本报告未提供相应拆分。
- `[I]` 净基差变化除资金利率和空头套保外，还可能来自CTD切换、转换因子、回购特殊性、交割期权和可交割券流动性；报告没有逐合约复算这些因素。
- `[I]` 跨期价差与理论值背离也可能受Carry、IRR、近远月CTD不同及移仓流动性影响；仅凭远月相对强势不能识别唯一原因。
- `[I]` 报告以地产龙头股价增速领先销售作为融资需求判断之一，但股价也会受到风险偏好和政策预期影响；领先相关本身不足以证明地产销售的因果路径。

  1. DR007连续处于政策利率上方且大行净融出继续下降；

  6. TL相对T持续转弱，T-TL价差重新上行。
