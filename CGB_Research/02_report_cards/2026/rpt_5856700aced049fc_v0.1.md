# 4. 传导链与竞争性解释 `[I]`

## 4.1 报告主链

报告主链一：长端前期快速上涨 → 浮盈积累 → 交易型机构获利了结、TL减仓 → TL跌幅大于TS/TF/T。该链为报告解释，账户行为证据不足，不能视为已证实因果。报告在策略栏**另行**提出关注`3*T-TL`回落；两者只能并列记录，不能把TL相对走弱写成价差回落的原因。机械上`Δ(3*T-TL)=3×ΔT-ΔTL`，必须按两腿价格变化独立复算。

报告主链二：公开市场操作维持流动性、DR001/DR007相对平稳 → 短端融资约束有限 → TS/TF相对抗跌 → 期限品种表现分化。该链适用于资金仍稳定的短期窗口，不代表短端绝对上涨。

报告主链三：后续超长期特别国债和专项债发行 → 久期供给增加 → 若配置盘吸收或央行对冲不足，则长端收益率上行压力增加 → TL相对承压。报告提出供给压力，但未量化发行节奏与需求缺口。

## 4.2 竞争性解释

- 同样的TL减仓下跌也可能来自套保增加、跨品种套利平仓、移仓换月或做市库存调整，而非单纯“浮盈兑现”。只有总持仓和价格无法区分。
- 长端弱于短端可能主要由政府债供给、期限溢价重估或股票上涨引发的资产再配置驱动；“避险情绪边际回落”只是候选解释。
- DR001/DR007平稳与短端抗跌同时出现并不证明前者单向导致后者；短端定价还受政策利率预期、现券供求、CTD变化和期现套利影响。
- `3*T-TL`回落可能来自T和TL任一端的价格、久期/DV01不匹配、主力切换或合约基差变化；应拆解腿部贡献后使用。
