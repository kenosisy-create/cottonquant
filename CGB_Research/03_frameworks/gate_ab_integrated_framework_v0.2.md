# 中国国债研究操作系统 v0.2（Gate A+B）

本框架不是六份报告的摘要、投票器或平均预测，也不形成方向性投资裁决。它把不同报告中可复用的方法组织成一条可审计的研究漏斗：

**上期观点冻结与复盘 → 国内结构锚 → 战术触发 → 海外事件门控 → 市场定价 → 行为确认 → 工具表达 → 到期证伪**

其中“海外事件门控”是Gate B新增的横向接口，不取代Gate A的六层控制台。任何海外观点即使自身正确，也只有穿过人民币/跨境桥梁并得到国内市场确认后，才允许成为中国国债解释变量；能否进一步映射到TS、TF、T或TL，还要单独通过期货微观结构门槛。

## 0. v0.2解决什么问题

### 0.1 研究单位由“研究员”改为“可检验模块”

- 不建立单一研究员的深度画像，不按机构或作者给观点投票。
- 报告作者、发布日期和分项数据截止日只承担来源追溯与预测复盘功能，不作为研究框架的主轴。
- 每份报告被拆成：机制、触发、定价、行为、工具、证伪和数据接口；相同模块跨报告合并，冲突模块同时保留。
- `[E]`仍必须保留`report_id + PDF物理页码 + 证据数据截止日或[U]`，因为“不过度纠结日期”不等于放弃审计链。

### 0.2 Gate B的三个最小增量

1. **周度变化协议**：先复核上一期，只写本周新增变化，不每周重建宏大叙事。
2. **事件分段协议**：把政策行动、票型、声明、记者会、市场定价和持续性分开。
3. **海外传导门控**：把美债、美元、油价或全球风险偏好视为候选外部状态，只有国内中介与价格响应确认后才进入CGB判断。

### 0.3 证据与输出契约

| 标签 | 含义 | 使用规则 |
|---|---|---|
| `[E]` | 报告明确陈述 | 必须给出report_id、物理页码和分项截止日或`[U]`；报告观点不自动成为事实 |
| `[I]` | 跨报告整合、传导假说或工程设计 | 必须指向证据锚并给竞争性解释，不得伪装为报告原话 |
| `[X]` | 报告外数据或官方资料 | 必须登记来源、字段、时点、版本、快照ID和抓取/计算规则 |
| `[U]` | 口径、时点、数值或图表含义不足 | 不用默认值补齐，不进入硬阈值或生产表达 |

周报中的每句话必须属于：事实、解释、市场定价、条件情景之一。每项市场判断仍须具备适用期限、传导机制、触发条件、证伪条件和跟踪指标。

## 1. 研究架构与状态机

| 层级 | 必答问题 | 最低通过条件 | 输出状态 | 未通过时 |
|---|---|---|---|---|
| 0. 上期复盘 | 上期触发、机制、市场对象和期限兑现了吗？ | 冻结旧版本、旧快照、旧阈值与工具映射 | confirmed / partial / falsified / unresolved / execution_mismatch | 不得先改阈值再评价 |
| 1. 国内结构锚 | 1—4季度的利率中枢和期限溢价由什么约束？ | 信用/需求、政策/供给、价格与反方证据至少各一项 | classified / mixed / unclassified | 不作中期方向外推 |
| 2. 战术触发 | 未来1天—4周什么变量改变资金、供给或预期？ | 事实时点、比较基准、持续性和传导对象齐全 | active / watch / expired | 只记事件，不写利多利空 |
| 2E. 海外门控 | 海外事件是否经过中国面对的中介并改变国内条件？ | 依次通过G0—G3；每级保留时间戳、幅度门槛和缺失状态 | external_only / bridge_open / domestic_conditions_confirmed / manual_pending | 不能把海外共变写成CGB因果 |
| 3. 市场定价 | 现券、曲线、期货和期现是否出现独立响应？ | 对象、方向、幅度、窗口和历史噪声比较可复核 | observed / no_material_move / ambiguous / unknown | 未冻结阈值前只允许manual_pending或unknown |
| 4. 行为确认 | 哪类机构、流量或量价仓在响应？ | 必须记录行为状态；若原观点明确依赖机构行为机制，至少需要两项不共享同一构造口径的行为证据 | confirm / contradict / mixed / unavailable / not_required | 依赖行为的观点未确认则阻断；其他观点数据缺失只降低置信度 |
| 5. 工具表达 | 应由现券、曲线、期货单边、跨品种、基差还是跨期表达？ | 按工具分支检查各自输入，不把期货门槛施加给现券 | expression_ready / no_expression | 不生成伪精确策略 |
| 6. 到期证伪 | 链条断在何处？ | 使用创建时冻结的条件和到期日 | breakpoint_layer + review_status | 新建版本，不覆盖旧观点 |

`[I]` 本状态机保留Gate A的六层框架，仅增加层0的强制前置和层2E的海外门控；尚需用户审阅和样本外验证。

## 2. 国内主链：海外信息不能绕过的底盘

### 2.1 结构锚

| 子模块 | 核心问题 | P0状态变量 | 禁止的直接外推 |
|---|---|---|---|
| 信用与需求 | 信用扩张是否连续并转为实体需求？ | 社融、居民中长贷、工业生产、地产、消费 | 单月改善不定义信用周期 |
| 通胀与增长 | 价格、生产和需求的方向是否一致？ | CPI/PPI、核心价格、生产和需求分项 | 全球通胀不能替代国内价格事实 |
| 货币与资金 | 政策锚和实际融资约束是否同向？ | 政策利率、DR001、DR007、R007-DR007、大行净融出、央行净投放 | 一次操作不等于政策转向 |
| 财政与供给 | 总量供给和久期供给是否被配置需求吸收？ | 分期限净融资、久期加权供给、发行进度、机构净买入 | 发行总额不等于长端冲击 |
| 资产需求 | 银行、保险、基金、理财、外资的行为是否同向？ | 分机构、分期限净买入，基金久期和ETF流量 | 基金样本不代表全市场 |

结构锚只回答季度以上的约束，不直接回答本周TS/TF/T/TL方向。若长期机制与短期价格相反，两套账本同时保留。

### 2.2 定价与工具必须分对象

| 对象 | 必须独立记录 | 审计边界 |
|---|---|---|
| 现券 | 2Y/5Y/10Y/30Y固定期限收益率、活跃券、成交与估值口径 | 收益率上升与价格下跌方向相反；活跃券切换不可忽略 |
| 曲线 | 2Y-10Y、5Y-10Y、10Y-30Y和蝶式 | 每条腿与正负号显式；不能用“曲线变陡”统括不同区段 |
| TS/TF/T/TL | 实际合约价格、结算、成交、持仓和主力映射 | 连续合约与实际合约分离；四品种不能混写 |
| 跨品种 | 固定公式、实际合约、腿部贡献及DV01中性版本 | `3*T-TL`回落不能由“TL更弱”直接推出；必须复算`3ΔT-ΔTL` |
| 跨期 | 同品种近月与远月、移仓期和两腿基差 | 近远月定义、换月和持仓必须冻结 |
| 期现 | 基差、净基差、Carry、IRR、CTD、转换因子 | 按`product + contract + bond`计算；任一关键字段为U即`no_expression` |

## 3. 海外事件五级门控

海外门控只决定“海外信息能否成为CGB解释变量”，不妨碍国内证据独立形成观点。

| 门级 | 必答问题 | 最低通过条件 | 未通过后的状态 |
|---|---|---|---|
| G0 `event_verified` | 真实发生了什么？ | 官方或可审计`[X]`事件源、准确时间戳；事实与报告解释分离 | event_unverified；只进入事件待核验队列 |
| G1 `external_priced` | 海外市场是否发生超出事件噪声的重新定价，驱动是什么？ | 冻结事件前基线、方向、最小有效幅度/历史噪声分位、持续窗口和两个独立证据族；历史门槛未回测前只能`manual_pending` | external_pricing_unconfirmed / manual_pending |
| G2 `bridge_open` | 冲击是否进入中国面对的中介？ | USD/CNH、CFETS、结售汇或外资流量至少一类形成达到门槛且方向一致的持续响应；DXY、VIX、MOVE只能作外部渠道证据，不能单独开门 | external_only / bridge_manual_pending；不归因CGB |
| G3 `domestic_conditions_confirmed` | 国内资金、政策空间、跨境流量、信用或供给是否出现方向一致的正向确认？ | 至少一项国内中介达到冻结门槛且`alignment=confirm`；“没有反向证据”或“数据缺失”不算确认 | bridge_only / domestic_manual_pending；CGB价格留到第3层独立检验 |
| G4 `expression_ready` | 市场定价已独立检验、行为状态已记录后，特定工具的输入是否完整？ | 按现券、曲线、期货单边、跨品种、期现或跨期的分支门槛检查；行为只在原论点依赖机构行为机制时作为硬门槛 | no_expression |

G1在历史事件噪声和持续性窗口完成回测前不得自动通过。每次人工判断至少记录：`baseline_window, direction, minimum_effective_move, noise_percentile, persistence_window, evidence_family_1, evidence_family_2, reviewer`。G2与G3的每条中介证据还必须记录`expected_sign, observed_sign, alignment`，其中`alignment=confirm|offset|ambiguous`；只有`confirm`可以使该证据晋级，`offset`是反向证据，`ambiguous`保持待审。

### 3.1 G4按工具分支，不共用一套期货门槛

| 工具分支 | 必须具备的最小输入 |
|---|---|
| 现券单边 | 券种或固定期限、DV01、流动性、估值/成交口径和持有期 |
| 现券曲线/蝶式 | 两腿或三腿定义、正负号、DV01、同源估值和流动性 |
| 期货单边 | 实际合约、CTD、转换因子、基差、合约DV01和主力/换月规则 |
| 期货跨品种 | 各腿实际合约、公式、DV01、换月和`腿部贡献` |
| 基差/净基差/IRR | 逐券现金流、全价/净价、CTD、转换因子、融资与交割规则 |
| 跨期 | 同品种近远月、移仓窗口、两腿成交持仓和两腿基差 |

### 3.2 G1必须先识别冲击渠道

| 渠道 | 核心指标 | 对CGB可能形成的中介 | 竞争性解释 |
|---|---|---|---|
| policy_path | OIS/SOFR、联邦基金期货、2Y美债 | 中美利差、人民币、国内政策空间 | 事件前定价过满、获利了结 |
| inflation_path | 远近端油价、实际利率、盈亏平衡通胀、通胀互换 | 输入性通胀、全球利率 | 远端油价下跌也可能来自需求走弱 |
| term_premium_supply | 10Y/30Y美债、期限溢价、MOVE、财政供给和拍卖 | 全球久期价格、风险补偿 | 沟通、供给、流动性和仓位可产生同向结果 |
| usd_liquidity | DXY、美元融资、USD/CNH | 汇率约束、跨境流量 | 风险偏好改善可抵消利差 |
| risk_off | VIX、MOVE、权益、信用利差 | 避险配置、股债再平衡 | 美元流动性挤兑与债券避险可能方向相反 |

同样是10年美债收益率上升，政策路径上移与财政供给/期限溢价上升对中国国债的含义不同，因此不得只按收益率正负号映射。

### 3.3 两只时钟

FOMC等美国事件必须保留两套窗口：

- 美国时钟：决议前 → 决议后 → 开场陈述后 → 记者会后 → 美国收盘 → T+1/T+5；
- 中国时钟：下一中国交易日开盘 → 收盘 → 第5个实际交易日。

若中国休市，以第一个实际交易日为起点。禁止把美国盘中反应与中国前一交易日价格拼接为“同步反应”。

事件响应面板属于**数据集**而不是单一指标，不进入一行一个unit的指标字典。建议主键与单位安全字段为：

`event_id, series_id, instrument_type, anchor_timestamp_utc, market_timezone, trading_calendar, market_session, window_id, china_response_trade_date, price_field, quote_convention, expected_sign, observed_sign, alignment, value, unit, source_snapshot_id`

`T+1/T+5`必须同时带交易日历；美债、DXY、USD/CNH、中债收益率和国债期货保持各自单位，通过`series_id + unit + quote_convention`解释，不能混成一个数值列后直接加总。

### 3.4 门控写入观点账本的建议字段

在现有`view_ledger.csv`后续版本中增加：

`snapshot_id, external_event_ids, external_channel, external_gate_status, response_window, expected_sign, observed_sign, alignment, behavior_required, behavior_status, expiry_at, breakpoint_layer`

其中`breakpoint_layer`受控为：

`structure_anchor | tactical_trigger | event_fact | external_pricing | cross_border_bridge | domestic_conditions | market_pricing | behavior | expression`

门控状态的合法顺序为：`event_unverified → event_verified → external_pricing_unconfirmed/manual_pending → external_priced → external_only/bridge_manual_pending → bridge_open → domestic_manual_pending/bridge_only → domestic_conditions_confirmed`。第3层市场定价完成独立检验、行为状态完成记录后，才允许检查G4；仅当原观点的传导机制依赖机构行为时，行为`confirm`才是硬门槛。其他观点若行为数据`unavailable`，应降低置信度但不自动返回`no_expression`。任一级失败均记录为对应`breakpoint_layer`，不得跳级。

## 4. 事件分段协议

所有政策、数据与地缘事件统一用以下步骤，不为FOMC单独建立一套不可复用叙事。

| 阶段 | 固定问题 | 输出 |
|---|---|---|
| T-1 基线 | 事件前市场已定价多少？ | 冻结隐含路径、收益率曲线、汇率和仓位快照 |
| T0 行动 | 正式决定、数值和生效时间是什么？ | `[X]`官方事实；未核验前只可用报告`[E]`转述 |
| T1 分歧 | 票型、声明变化和内部异议是什么？ | 行动与分歧分列，不把异议票当成下一次行动 |
| T2 沟通 | 反应函数、门槛和不确定性是否变化？ | 明示内容与政治/动机推断分开 |
| T3 定价 | 短端、长端、汇率和风险资产如何分阶段响应？ | 盘中近似值、收盘值和方向分开 |
| T+1/T+5 持续性 | 首轮反应保留、反转还是扩散？ | persistence状态与链条断点 |
| 下一中国交易日 | 人民币、国内条件、现券和期货是否依次响应？ | 先记录G2/G3，再由第3层独立检查市场定价；工具数据齐全后才检查G4 |

事件报告的价值在于提供“新增信息的分层方法”，不是把单次盘中走势固化为长期规律。

## 5. 冲突不是噪声：预测声明账本

### 5.1 当前三个需要保留的冲突

| 冲突 | 报告主张 | 关系判定 | 处理 |
|---|---|---|---|
| 10Y美债区间 | FOMC事件卡片：4.5%-5.0%；海外半年展望：3.95%-4.65% | `scenario_conflict + partial_overlap`；中点相差约45bp | 不平均、不扩成3.95%-5.0%“共识”；对齐触发条件后分别复盘 |
| 2026H2政策路径 | FOMC事件卡片：9月加息是活跃情景、连续加息非清晰基准；海外半年展望：按兵不动为基准 | `partial_overlap`，尚非hard_conflict | 区分base与active_alternative，观察通胀、就业、隐含路径与票型扩散 |
| 国内长短期叙事 | Gate A保留结构性低利率机制；周度报告给出单边中性、长端相对偏弱和中期调整压力 | 不同期限、可同时成立 | 结构锚与战术风险分账，不用本周价格改写季度机制 |

另有报告内部冲突必须保留为`[U]`：周度报告p1称TL“明显减仓回落”，p5表4却给出未说明比较基准的持仓环比`+2,560`手；海外展望对CPI高点月份、增长预测和油价阈值存在不同口径。这些记录不能参与强结论。

### 5.2 不可覆盖的预测声明表

建议在Gate B获批后创建`forecast_claims.csv`，最小字段为：

`forecast_claim_id, report_id, comparison_group_id, related_claim_id, relation_type, target, forecast_origin, horizon_start, horizon_end, scenario_role, lower_bound, upper_bound, policy_path, triggers, falsifiers, status, last_review_snapshot`

`scenario_role=base|active_alternative|tail`；关系枚举为：

`compatible | partial_overlap | scenario_conflict | hard_conflict | not_comparable | stale`

比较顺序固定为：期限 → 对象/单位 → 场景角色 → 触发/证伪 → 同一冻结快照下的市场隐含路径与驱动分解。禁止按作者声望、报告数量或发布时间自动覆盖。

## 6. 周报执行协议：先复盘，后写变化

### 6.1 先冻结上一期

每周开始时冻结：观点版本、触发条件、证伪条件、适用期限、数据快照、实际合约、CTD/转换因子、计算规则和到期复核日。不得先看本周结果再修改旧阈值。

### 6.2 逐条复盘

1. 触发是否发生；
2. 预定中间变量是否响应；
3. 海外观点停在G0—G4哪一级；
4. 目标市场是否在预定窗口响应；
5. 行为证据确认、反向还是缺失；
6. 现券机制若成立，期货是否因CTD、基差、Carry、IRR或换月产生执行偏差。

状态仍为`confirmed / partial / falsified / unresolved / execution_mismatch`，但必须增加`breakpoint_layer`。触发没有发生是`unresolved`，不是观点失败；证伪条件发生即`falsified`，不得无限延长期限。

### 6.3 本周只写变化量

周报固定回答：

- 结构锚是否变化；
- 本周新增/到期的战术触发；
- 海外门控停在哪一级；
- 市场新定价了什么；
- 行为证据确认还是反向；
- 哪些工具从`no_expression`晋级，哪些因数据或微观约束降级；
- 上期观点的状态和断点。

### 6.4 新观点晋级门槛

每条新观点必须具备：适用期限、触发条件、中间变量、目标市场对象、证伪条件、观察窗口、数据快照、到期复核日和上一版本链接。未通过海外门控的事件可以作为风险项，但不得成为CGB方向结论的主证据。
